# Contributing

Thanks for taking a look. Keep changes small and readable; this project is meant to be easy to learn from.

Before opening a pull request:

1. Install Python 3.10 or newer and run `python -m pip install -r requirements.txt`.
2. Run `python -m unittest discover -s tests -v`.
3. Update `docs/API.md` and the README if an endpoint or setup step changes.
4. Never commit `.env`, database files, server keys, player data, or real invite codes.

For security issues, avoid posting working secrets or exploit details in a public issue. This is an early prototype without a formal security response process, so do not use it for valuable competitive rankings without your own review.
